# Simulateur de terminal

Un faux terminal pour t'entraîner à taper les commandes des cours, sans risque. Choisis un shell vu en cours (**bash** pour Linux, **cmd** ou **PowerShell** pour Windows) et réalise les missions. Dans bash, tu peux aussi lancer les autres shells du cours (`sh`, `ksh`, `csh`, `tcsh`).
