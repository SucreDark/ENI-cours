# Réviser

Tous les outils pour réviser **avec le contenu des cours** (rien d'autre). Ta progression est enregistrée dans ce navigateur.

<div class="grid cards" markdown>

-   :material-help-circle-outline:{ .lg } **[Quiz](quiz.md)**

    Questions au hasard (tous les cours ou un seul), chrono, score et liste « à revoir ».

-   :material-timer-sand:{ .lg } **[Examen blanc](examen.md)**

    20 questions, 30 minutes, correction seulement à la fin, note sur 20.

-   :material-cards-outline:{ .lg } **[Flashcards](flashcards.md)**

    Sigles, commandes et exercices, avec répétition espacée.

-   :material-printer:{ .lg } **[Fiches mémo](../fiches/index.md)**

    Une page par cours, imprimable en PDF.

-   :material-console-line:{ .lg } **[Commandes](commandes.md)**

    Toutes les commandes des cours, filtrables, avec le lien vers le module.

-   :material-book-alphabet:{ .lg } **[Glossaire](glossaire.md)**

    Les sigles des cours (et les infobulles au survol dans les pages).

-   :material-monitor-shimmer:{ .lg } **[Simulateur](simulateur.md)**

    Faux terminal bash, cmd et PowerShell avec des missions.

-   :material-calculator-variant:{ .lg } **[Outils réseau](outils.md)**

    Calculatrice IPv4 et convertisseur binaire / décimal / hexa.

-   :material-notebook-edit-outline:{ .lg } **[Mon carnet de TP](carnet.md)**

    Toutes tes notes de TP, exportables.

-   :material-trophy-outline:{ .lg } **[Badges](badges.md)**

    Tes succès débloqués.

</div>

## :material-cellphone-arrow-down: L'appli sur ton téléphone

Le site s'installe comme une vraie appli : icône sur l'écran d'accueil, plein écran, et **tout marche hors ligne** (cours, fiches, quiz, simulateur…).

<div id="app-installer"></div>

!!! tip "Astuces"
    - Le bouton :material-palette: en haut change le thème (néon, ambre, cyberpunk, matrix).
    - Le bouton :material-cellphone-arrow-down: en haut installe l'appli (s'il n'apparaît pas, voir juste au-dessus).
    - Il y a un terminal caché quelque part… essaie la touche ++"²"++ 😉
