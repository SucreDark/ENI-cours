# Module additionnel – VMware Workstation

!!! info "Même module qu'en Systèmes clients"
    Ce module reprend celui vu en Systèmes clients Microsoft : tout le contenu (virtualisation, hôte / invité, hyperviseur, ressources, réseau, import/export) est sur la page
    [Module additionnel – VMware Workstation](../systemes-clients-microsoft/m02b-vmware-workstation.md).

**Plan du module** : objectifs · la virtualisation des systèmes · VMware Workstation et les ressources · VMware Workstation et le réseau · VMware Workstation et ses spécificités · démo création d'une VM · import et export de VM · démo import/export · conclusion.

!!! abstract "À retenir"
    - **Hôte** = ordinateur physique qui possède les ressources · **système invité** = VM avec son propre OS.
    - L'**hyperviseur** fait le lien entre l'hôte et les VM et partage les ressources.
    - **Importer** une VM : depuis son dossier d'accueil ou une archive **.ovf / .ova** · **exporter** : copier son dossier d'accueil ou créer une archive .ovf / .ova.
